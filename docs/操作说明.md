# 操作说明

本文档按业务角色介绍系统功能与演示操作步骤，方便作品答辩与功能验收。

## 一、角色与账号

| 角色 | 入口 | 账号 |
|---|---|---|
| 普通用户（师生） | 注册新账号 | 自行注册 |
| 平台管理员 | 登录页 | admin / admin123 |

## 二、演示流程（推荐顺序）

### 场景：完整交易闭环

1. **注册两个普通用户**（如 user1、user2），分别登录。
2. **user1 发布物品**（标价转让 + 以物换物各一件）：
   - 顶栏「发布闲置」→ 填写标题、分类、流转类型、价格/换物、交易地点、描述 → 上传图片 → 提交。
   - 提交后状态为「待审核」，前台首页不展示。
3. **管理员审核**：
   - 登录 admin → 用户菜单「管理后台」→「物品审核」→ 对待审核物品点「通过」。
4. **user2 浏览与咨询**：
   - 首页可看到通过审核的物品；按分类筛选、关键词搜索。
   - 进入详情页 → 留言咨询 → user1 在详情页留言区回复。
5. **user2 收藏 + 预约**：
   - 详情页点「收藏」→ 到「我的收藏」查看。
   - 详情页点「预约线下交易」→ 选择期望时间、填写备注 → 提交。
6. **user1 处理预约**：
   - 「我的预约」→「别人预约我的」→ 同意/拒绝。
7. **user1 标记成交**：
   - 「我的发布」→ 对已预约的物品点「标记成交」，物品状态变为已成交。

### 场景：双端数据同步演示

1. 电脑浏览器（PC 视图）打开系统，手机浏览器（移动视图）打开同一系统。
2. 手机端发布一件物品（手机拍照/相册上传图片）→ 电脑端首页**无需刷新**，最长 30 秒内自动出现该物品（轮询同步）。
3. 电脑端管理员下架该物品 → 手机端详情页自动刷新为「已下架」。
4. 手机端修改个人昵称/头像 → 电脑端顶栏个人信息自动更新。

### 场景：管理员违规处理

1. 用户发布违规内容（如重复灌水物品、不当留言）。
2. admin →「物品审核」→ 直接「下架」违规物品；「拒绝」不合规的待审核物品。
3. admin →「用户管理」→ 搜索违规用户 →「禁用」；该用户再次操作接口会提示「账号已被禁用」。
4. admin →「留言管理」→ 删除违规留言。
5. admin →「数据看板」→ 查看总发布/成交/上架/待审核/用户数、分类占比饼图、状态分布、近 7 天发布趋势。

## 三、功能操作清单（按页面）

### 1. 首页
- 分类标签：全部 / 书籍 / 电子产品 / 代步工具 / 生活用品 / 其他
- 类型筛选：全部 / 标价转让 / 以物换物
- 顶栏搜索：输入关键词回车检索
- 卡片点击进入详情；右下角分页

### 2. 物品详情页
- 多图预览（点击大图可放大；多图时下方缩略图切换）
- 标价转让显示价格；以物换物显示「以物换物 · 不花钱」
- 收藏 / 取消收藏；预约线下交易（选择时间 + 备注）
- 留言：输入内容发表；发布者可回复（蓝色回复条）；留言人/发布者/管理员可删除

### 3. 发布页（发布/编辑复用）
- 发布后进入「待审核」状态
- 编辑：从「我的发布」点编辑进入，保存后状态不变

### 4. 我的发布
- 查看全部：待审核 / 上架中 / 已成交 / 已下架
- 操作：查看、编辑、重新上架、下架、标记成交、删除（级联删除留言/预约/收藏）

### 5. 我的预约
- Tab1 我发起的：查看对方处理状态（待确认/已同意/已拒绝）
- Tab2 别人预约我的：同意 / 拒绝

### 6. 个人中心
- 点击头像区域上传新头像（立即预览，保存后生效）
- 修改昵称、手机号；账号与注册时间只读

### 7. 管理后台
- 用户管理：搜索、禁用/启用（管理员账号不可操作）
- 物品审核：按状态筛选 + 关键词搜索；通过 / 拒绝 / 下架
- 留言管理：搜索内容、删除违规留言
- 数据看板：ECharts 图表实时统计

## 四、数据流转规则说明（答辩要点）

| 规则 | 实现方式 |
|---|---|
| 新发布物品 | 默认 `待审核(0)`，管理员通过后变为 `上架(1)` 前台可见 |
| 前台列表 | 只返回 `上架(1)` 的物品，游客无需登录可浏览 |
| 双端同步 | 前端每 30 秒轮询 `GET /api/goods`、留言、预约接口，静默刷新 |
| 图片存储 | 上传到后端本地 `upload/` 目录，URL 形如 `/upload/20240101120000123456.jpg` |
| 预约去重 | 同一用户对同一物品最多一条「待确认」预约 |
| 权限控制 | 后端按接口注解强制校验（登录 / 管理员），前端路由守卫配合 |
| 禁用账号 | 登录时拦截 + 每次请求拦截器查库校验，双保险 |
